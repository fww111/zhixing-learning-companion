# React 页面重构规范

本规范用于把当前产品页面图和商业级视觉方案落到现有 React/Vite 前端。实现范围只覆盖 `apps/web`，不得破坏现有 FastAPI 接口、JWT 鉴权、课程级画像、课程知识库、知识图谱、学习路径、OpenMAIC 课堂和学习评估链路。

相关设计稿：

- `docs/design/product-page-mockups.html`：现有产品页面图。
- `docs/design/commercial-learning-site-design-options.html`：5 套商业级成熟学习网站候选视觉方案，仅保留 HTML，不转 PDF。

## 设计定位

- 产品形态：企业级教育工作台，不做营销落地页，不做单页大杂烩。
- 流程基调：课程优先、课程级隔离、每页只承载一个明确工作阶段。
- 视觉目标：高密度、清晰、专业、适合学习平台长时间使用。
- 功能约束：前端样式可以重构，但不能移除现有功能、接口和数据闭环。
- 图谱颜色只表达掌握状态：灰色未学习、红色严重弱项、橙色掌握基础、浅绿色达标良好、绿色精通。

## 路由与页面职责

| 路由 | 页面 | 页面职责 | 关键组件 |
| --- | --- | --- | --- |
| `/auth` | 登录注册页 | 仅处理账号登录和注册，登录成功后进入课程选择 | `AuthPanel` |
| `/courses` | 课程选择/我的课程页 | 选择 `C语言程序设计` 或 `Python程序设计`，创建或切换当前课程 | `CoursesPage` |
| `/courses/:courseId/profile/interview` | 课程画像访谈页 | 为当前课程构建专属学生画像，完成后进入该课程知识库 | `ProfileInterviewPanel`, `ProfilePanel` |
| `/courses/:courseId/knowledge-base` | 课程材料与知识库页 | 上传 PDF/PPT/PPTX、确认内置知识库、展示解析和索引状态 | `MaterialUploadPanel`, `KnowledgeChunksPanel` |
| `/courses/:courseId/graph` | 知识图谱页 | 生成/展示当前课程知识图谱，点击节点进入学习页 | `KnowledgeGraphPanel` |
| `/courses/:courseId/learning-path` | 学习路径页 | 根据当前课程画像、知识图谱和掌握度生成路径，支持补救任务 | `CourseLearningPathPage` |
| `/courses/:courseId/assessment` | 学习评估页 | 展示课程级多维评估、掌握趋势和错题集入口 | `AssessmentPanel` |
| `/courses/:courseId/assessment/wrong-questions` | 错题集页 | 按图谱章节归档错题，支持选择题和编程题重做 | `CourseWrongQuestionsPage` |
| `/courses/:courseId/knowledge/:nodeId` | 知识点学习页 | OpenMAIC 标准课堂、文档、思维导图、代码练习、随堂测试和评估闭环 | `KnowledgeLearningPage` |

保留旧 `/profile/interview` 兼容路由时，不应作为主流程入口。主流程必须从 `/courses` 选择课程后进入课程级画像。

## 全局布局规范

- 登录页不使用应用壳，采用独立认证布局。
- 登录后的页面统一使用 `AppLayout`：
  - 左侧固定主导航，优先显示“课程知识库”和“学生画像”顺序要求。
  - 导航按钮必须根据当前课程状态启用，不允许出现 C 课程可用、切回 Python 后按钮变灰的状态同步问题。
  - 当前课程明确显示在顶部或侧边栏，用户可以回到“我的课程”切换当前课程。
  - 主内容区只展示当前路由，不把画像、知识库、图谱、路径、课堂和评估混在同一屏。
- 登录后的所有页面右下角挂载智能辅导悬浮窗；悬浮窗不能遮挡页面主操作按钮，小屏幕降级为底部抽屉。
- 图标使用 `lucide-react` 或现有图标库，不使用 emoji 作为结构图标。

## 页面落地规范

### 登录注册页

- 只处理登录、注册、错误反馈和加载状态。
- 登录成功后进入 `/courses`。
- 不在登录页展示复杂学习功能。

### 课程选择/我的课程页

- 首屏显示两门主课程：`C语言程序设计`、`Python程序设计`。
- 支持用户将某一门课设置为当前课程。
- 切换当前课程后，侧边栏知识图谱、学习路径、学习评估等入口都必须基于新课程刷新状态。
- 用户确认使用内置课程前，不应自动挂载内置知识库。
- 支持创建课程，创建后流程进入该课程画像构建。

### 课程画像访谈页

- 左侧为对话区：展示当前大模型问题、回答输入区和轮次状态。
- 右侧为画像维度面板：展示专业、目标、基础、时间偏好、资源偏好、动机、约束、评估偏好等耐久数据。
- 问题必须由大模型基于画像缺口动态生成，不能固定问题循环。
- 画像维度齐全后自动确认，不需要用户手动点击确认。
- 完成后主按钮跳转到该课程知识图谱或知识库的下一步入口，文案必须与实际跳转一致。

### 课程知识库页

- 支持多文件上传，包括多个 PDF/PPT/PPTX。
- 页面顶部展示解析流水线：上传 -> MinerU/本地解析 -> 分块入库 -> BGE-M3 向量化 -> Milvus 索引 -> Neo4j 图谱。
- 不重复摆放“上传自定义课程”和“使用内置课程”按钮。
- 已入库材料的删除按钮必须可用，并清理文件、MySQL chunk、Milvus 向量和旧图谱任务。
- “重建向量索引”失败时显示具体 Milvus 或 BGE-M3 错误，不能只停留在“待重建索引”。

### 知识图谱页

- 图谱结构和样式应保持当前用户认可版本，不因页面重构减少节点数量。
- 根节点必须是课程名。
- 节点颜色只绑定掌握状态，不按章节或知识类型做彩色分类。
- 图谱下方或右侧展示文字描述、前置知识、后续知识、相关知识和来源证据。
- 点击节点进入 `/courses/:courseId/knowledge/:nodeId`。

### 学习路径页

- 使用游戏地图式关卡展示。
- 路径来自 `POST /api/courses/{course_id}/learning-paths/plan`，不能写死。
- 尊重画像时间偏好和约束。例如 `每天1小时` 必须按每日可学排期；`一周1小时，周末才有空` 只排周末且总时长约 60 分钟。
- 有三级节点时，任务卡规划三级知识点；二级章节节点只作为章节上下文。
- 今日日期对应的任务标记为“今日任务”；其他任务按画像可用时间向后规划。
- 学生可以完成今日任务后继续学习后续任务。
- 评估未达标后刷新路径，应插入薄弱点专项补救节点。

### 知识点学习页

- 学习页主体使用 OpenMAIC 前端课堂，大屏展示，占满可用白色内容区域。
- 课堂外仍展示闭环审计信息：本地证据、检索轨迹、图谱约束、校验分数、辩论摘要、最终决策。
- 三个主要资源按钮：该节课文档、该节课思维导图、编程练习。
- 思维导图必须是树状导图结构，不能只是知识点列表。
- 编程练习题只给题目要求，不直接给答案；用户在浏览器编辑器中编写并运行。
- 课堂状态需要保存，同一知识点重新进入时优先读取缓存；点击“重新生成”才清理缓存并重新生成。

### 学习评估页

- 评估包含选择题、主观题/简答、编程题、课堂行为数据和错题趋势。
- 编程题按用户运行结果和期望输出判分。
- 综合评分后更新掌握度、学生画像、知识图谱颜色和后续路径。
- `掌握基础` 视为未达标；只有 `达标良好` 和 `精通` 算通过。
- 页面右侧不展示完整学生画像，改为多维评估可视化、薄弱维度、学习行为和错题集入口。
- 错题集只在评估页保留入口，点击进入独立错题集页面。

### 错题集页

- 错题按当前课程知识图谱章节/小节分组展示。
- 选择题展示原题、选项、学生答案、正确答案和重做按钮。
- 编程题展示题目要求、期望输出、历史输出和重做编辑器。
- 重做正确后调用评估提交逻辑，展示已解决状态，并触发该知识点评分更新。
- 切换课程后不得显示其他课程错题。

### 智能辅导悬浮窗

- 支持文字输入、图片上传和浏览器语音输入。
- 发送请求时自动带上当前 `course_id`、`node_id` 和页面上下文。
- 图片问题通过后端 Qwen3.7-Plus 多模态模型理解，再结合 Agentic RAG 证据生成回答。
- 学生端回答只展示自然语言讲解和操作建议，不展示“本地知识库证据”“知识图谱关系”“结构化讲解”等调试区块。
- 请求超时时显示可恢复错误，不清空已输入文本和附件。

## 组件与样式约束

- 卡片圆角不超过 8px，工具面板、列表、表格保持紧凑但可读。
- 按钮和表单控件最小高度不低于 44px。
- 不使用渐变球、装饰性光斑和过度营销式 hero。
- 不把页面区块全部做成悬浮卡片；工具卡只用于重复项、表单、状态面板和课堂辅助面板。
- 文本不能溢出按钮和卡片，移动端降级为单列布局。
- 使用语义状态类名表达掌握状态，例如 `mastery-unlearned`、`mastery-weak`、`mastery-basic`、`mastery-good`、`mastery-proficient`。

## 验收标准

- `npm run build` 通过。
- 登录后先进入 `/courses`。
- 未完成当前课程画像时，课程页面跳转到 `/courses/:courseId/profile/interview`。
- 切换 C/Python 当前课程后，侧边栏和所有页面数据立即基于当前课程刷新。
- 知识图谱节点数量和结构不因样式重构减少。
- 节点颜色只表达掌握状态。
- 学习路径由后端动态规划，补救任务可在评估未达标后出现。
- 知识点学习页主表面是 OpenMAIC 课堂，同时展示 Agentic RAG 和多智能体闭环证据。
- 学习评估页有错题集入口，错题集页可重做并更新评分。
- 全局智能辅导在所有登录后页面可见，文字/图片问题都能基于当前课程回答。
