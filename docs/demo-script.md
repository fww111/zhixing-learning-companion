# 7 分钟演示视频脚本

## 0:00-0:40 场景引入

小明是计算机专业大二学生，正在学习 `Python程序设计`，同时后续还要学习 `C语言程序设计`。两门课的基础、薄弱点和学习节奏不同，因此平台必须为每门课建立独立画像、知识库、知识图谱和学习路径。

## 0:40-1:20 登录与课程选择

展示登录后进入 `/courses`。用户选择 `Python程序设计`，系统判断该用户该课程是否已有画像；没有画像则进入课程专属画像访谈。强调切换到 `C语言程序设计` 时，画像、材料、图谱、路径和评估数据都独立。

## 1:20-2:10 对话式课程画像

展示课程画像访谈：首问固定，后续由 DeepSeek V4 Pro 根据画像缺口追问。右侧画像面板逐步更新专业、年级、学习目标、知识基础、时间偏好、资源偏好、薄弱点、约束和评估偏好。画像完整后自动确认。

## 2:10-3:10 课程知识库与知识图谱

进入课程知识库页面，上传 PDF/PPT/PPTX 或确认内置知识库。展示 MinerU 解析、MySQL chunk、BGE-M3 向量化、Milvus 索引和 Neo4j 图谱构建流水线。切到知识图谱页，展示以课程名为根节点的完整知识结构和掌握状态颜色。

## 3:10-4:10 动态学习路径

进入学习路径页，展示路径由课程画像、知识图谱和掌握度共同生成。说明系统会尊重“每天 1 小时”或“周末 1 小时”等时间约束；有三级知识点时，路径规划具体知识点而不是章节标题。评估未达标后会插入薄弱点专项补救关卡。

## 4:10-5:20 OpenMAIC 标准课堂与多智能体资源

点击路径中的知识点进入学习页。展示 OpenMAIC 标准课堂作为主学习表面，同时展示该节课文档、树状思维导图和编程练习。说明课堂大纲由 DeepSeek V4 Pro 基于 Agentic RAG + 知识图谱生成，Milvus 负责召回，最终证据来自 MySQL 原文 chunk。

强调课堂状态会保存：退出后重新进入同一知识点不重复调用大模型；点击重新生成才清理缓存并重新提交 OpenMAIC。

## 5:20-6:10 学习评估与错题闭环

课堂结束后进入随堂测试和学习评估。展示题库 Agent 生成的当前知识点专业选择题和编程题，编程题只给任务要求和期望输出，学生在浏览器中编写并运行。展示综合评分、掌握状态和评估解释。

若知识点未达标，系统更新画像薄弱点、知识图谱节点颜色和后续学习路径，并插入薄弱点专项补救任务。进入错题集，展示错题按章节归档；重做正确后重新写入评分并更新路径。

## 6:10-6:40 全局智能辅导

打开右下角智能辅导悬浮窗，在当前课程下输入问题或上传截图。说明智能辅导通过 Agentic RAG 检索当前课程 MySQL 原文证据，并用 Neo4j 图谱约束回答；图片理解默认使用 Qwen3.7-Plus。学生端只展示自然回答，不暴露原始 RAG 调试块。

## 6:40-7:00 技术亮点与总结

总结技术亮点：多课程隔离、课程级画像、MinerU + MySQL + BGE-M3 + Milvus + Neo4j、Agentic RAG、LangGraph 多智能体闭环、OpenMAIC 标准课堂、Qwen TTS、Qwen3.7-Plus 智能辅导、错题重做、评估驱动画像和路径动态更新。系统把“课程材料、学生画像、图谱约束、资源生成、学习评估、错题补救、智能辅导”连成可追溯闭环。
