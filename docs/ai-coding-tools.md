# AI Coding 工具说明

本项目开发过程中使用 Codex 作为 AI Coding 辅助工具，主要协助：

- 解读赛题需求并拆解实施计划。
- 生成和维护 FastAPI 后端、SQLAlchemy 模型、Pydantic Schema、Agent 模块和测试。
- 生成和维护 React/Vite 前端页面、路由守卫、学习页组件和评估组件。
- 协助排查课程画像、知识库、知识图谱、学习路径、OpenMAIC 课堂、智能辅导、错题集和学习评估链路中的问题。
- 编写和更新 PRD、技术方案、部署、测试、演示脚本、PPT 大纲和 UI 设计稿文档。

协作要求：

- AI 生成代码必须经过测试或明确标注未验证范围。
- 新增后端行为应优先补充或更新测试。
- 真实 Provider Key、MinerU Token、Neo4j 密码和 Qwen TTS Key 只能放本地 `.env`，不得写入代码、文档示例或提交记录。
- Mock LLM 必须保留，用于无外部 API 的演示兜底。
- 课程级数据隔离是核心约束，任何涉及画像、材料、chunk、Milvus、Neo4j、路径、课堂和评估的代码都必须带当前 `user_id + course_id` 上下文。
- 资源生成必须遵守 Agentic RAG + 知识图谱约束，Milvus 只做召回，最终证据来自 MySQL 原文 chunk。
- 智能辅导回答同样必须遵守课程级 RAG 约束；图片理解使用 Qwen3.7-Plus 配置，普通学生 UI 不展示原始 RAG 调试块。
- 学习评估题库必须是当前知识点专业题，选择题要保存动态正确答案索引，编程题不能直接暴露答案。
- 错题集重做属于评估闭环，修复时要确认评分、画像、掌握度和路径都会更新。
- 关键业务逻辑应保持清晰模块边界，便于人工审查和二次开发。
