# PPT 大纲

1. 赛题痛点：课程资源分散、路径不清、学习反馈无法持续影响后续规划。
2. 系统定位：多课程、课程级隔离的个性化学习多智能体平台。
3. 典型场景：同一学生分别学习 `Python程序设计` 和 `C语言程序设计`，两门课画像与学习数据独立。
4. 产品流程：登录 -> 课程选择 -> 课程画像 -> 知识库 -> 知识图谱 -> 学习路径 -> 标准课堂 -> 学习评估 -> 错题集 -> 动态重规划。
5. 课程专属学生画像：多维画像、对话式构建、随学随新。
6. 本地知识库：MinerU 解析、MySQL chunk、BGE-M3 向量化、Milvus 召回。
7. 课程知识图谱：DeepSeek 抽取、Neo4j 存储、掌握状态颜色和图谱约束。
8. Agentic RAG：Milvus 召回、MySQL 原文回表、Neo4j 关系约束，减少幻觉。
9. 多智能体闭环：分析、检索、生成、校验、辩论、决策。
10. OpenMAIC 标准课堂：课堂生成、Qwen TTS、3D/代码/游戏/模拟交互策略。
11. 动态学习路径：尊重画像时间约束，未达标插入薄弱点专项任务。
12. 专业题库生成：题库 Agent 根据当前知识点生成选择题和编程题，编程题不给答案、浏览器内运行判分。
13. 学习评估：课堂状态、题库、编程、行为数据、综合评分、画像与图谱回写。
14. 错题集闭环：按章节归档错题，重做正确后重新评分并更新路径。
15. 全局智能辅导：文字、图片、语音输入，Qwen3.7-Plus 图片理解，Agentic RAG 增强回答。
16. 商业级页面方案：展示 5 套 HTML 设计稿候选。
17. 技术架构：React/Vite、FastAPI、MySQL、Milvus、Neo4j、DeepSeek、Qwen3.7-Plus、OpenMAIC。
18. 演示与验收：两门课数据隔离、完整资源生成、评估/错题驱动路径更新。
